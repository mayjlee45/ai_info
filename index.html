💻 AI교육장 환경 안내

  • 교육장에 강사용 PC가 준비되어 있으며 인터넷 사용이 가능합니다.
  • USB, 외장 HDD 연결은 불가합니다.
  • 개인 노트북 반입은 가능하나, 노트북의 인터넷 연결은 제한됩니다.
  • 노트북을 반입하실 경우 사전에 모델명과 S/N(시리얼) 번호를 알려주셔야 부대 반입이 가능합니다. ※ 출입 당일에는 신청이 불가하니 반드시 사전에 통보해 주세요.

🍚 모바일 식권(PAYCO) 안내

식사는 PAYCO 모바일 식권으로 이용합니다. 아래 순서대로 준비해 주세요.

조식 4,500원 예약 전날 22시까지
중식 5,000원 당일 09:30까지
석식 5,500원 당일 15:00까지

⏰ 위 시간이 지나면 해당 식사는 예약(구매)할 수 없으니 시간 내에 미리 예약해 주세요.

1. 앱 설치 및 가입

  1. App Store 또는 Google Play에서 'PAYCO' 또는 '페이코'를 검색해 설치합니다.
  2. PAYCO 앱 설치 후 회원가입까지 완료합니다.

📱 QR로 바로가기

카메라로 QR을 찍으면 PAYCO 앱 설치 / 식권 구매 페이지로 이동합니다.

링크로 열기 (새 창)

🔍 QR을 클릭하면 크게 볼 수 있어요.

2. 식권 구매하기

  1. PAYCO 앱 실행 → 하단 [결제] 클릭 → [기업복지] 항목 클릭
  2. [식권 예약] 클릭 (공지: "정보통신학교 식당 예약 페이지")
  3. 희망 식사 (조식 / 중식 / 석식) 선택 → 예약일자 및 시간 선택
  4. 결제수단으로 결제 ※ 페이코 포인트로 결제 시 1% 적립

3. 식권 사용하기

  1. PAYCO 앱 → 우측 상단 [MY] 클릭 후 아래로 스크롤
  2. [식권] 또는 [전체보기] 클릭 ※ 유효기간(사용일자) 확인
  3. 해당 식권의 [교환권 사용하기] 클릭
  4. 식당 단말기에 바코드를 스캔한 후 식사
